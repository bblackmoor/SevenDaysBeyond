# Installable builds

Download [SevenDaysBeyond-0.6.0.zip](SevenDaysBeyond-0.6.0.zip) using the download button on its GitHub file page. This is the same package deployed on ANNWN.

Close the game, extract the ZIP, and copy the complete `SevenDaysBeyond` folder to your game’s `Mods` directory, replacing the older Beyond companion. Keep `LITW_MultiWorld` and `0_TFP_Harmony`, and launch without EAC as before. Copy the DLL, ModInfo.xml and the complete Config folder together. Do not copy the source directory as an installed mod.

The same ZIP works for clients and dedicated servers. Server administrators must preserve their existing `BoundaryTest.xml`; this ZIP does not overwrite it.

The adjacent `.sha256` file records the ZIP checksum. [Testing and localization](../docs/localization.md).
